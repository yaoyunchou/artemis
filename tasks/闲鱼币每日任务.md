# 闲鱼币每日任务

下次执行时，把下面「可直接粘贴的任务」整段交给 Flash。一次只跑这一份。不要把多条任务改写成「能做的都做」。

## 可直接粘贴的任务

打开闲鱼（包名 com.taobao.idlefish），只完成下面清单里看得到的行。做完一条必须回到「任务奖励」列表，再做下一条。全部处理完后停止，并逐条说明结果是「已领取」「已浏览并领取」「未找到」或「跳过」。

先按规律判断，再点。不要把每一行当成第一次见到。

- 按钮已经是「领取奖励」：点一次就结束。不要进入活动，不要再做一遍。
- 文案是「滑动 N 秒」「浏览 N 秒」「逛一逛」：点进去后只做互动约 20 秒（缓慢上滑两到三次，或停在页面上）。页面出现「任务完成」或倒计时结束就立刻返回。不要把倒计时滑满很多轮，不要点进商品。
- 文案是「玩一局」「开始游戏」「闯关」「小游戏」：直接跳过。不要点「开始游戏」「继续玩」，不要连消除、不要扔骰子。若已经在游戏里，点关闭或「残忍离开」，回到列表。
- 「得骰子」「限时惊喜」「扔骰子寻宝」：只关弹窗。不要掷骰子，不要为了多一颗骰子去看广告。
- 同一按钮点过一次没有变化，就换下一条。不要连点同一个骰子、同一个领取、同一次滑动。

### 怎么进入列表

1. 用启动应用打开闲鱼。确认前台是闲鱼首页。如果前台是淘宝、支付宝或别的应用，先返回，不要在那个应用里继续点。
2. 点首页右上角橙色圆形图标，上面有「领」或「签到」。元素列表里没有这一项时，点右上角该图标，不要点首页信息流。点错一次就停，改看右上角这个图标，不要在首页连续乱点。
3. 页面加载时等待大约 4 秒。出现「得骰子赚闲鱼币」「限时惊喜」或任何全屏弹窗时，只点关闭。不要点骰子、开始、去赚、立即领取。
4. 点「任务奖励」，停在任务列表上。看不到「任务奖励」时，只在当前闲鱼币页面里找它。不要为了找列表而重新打开闲鱼。
5. 如果「通过首页访问闲鱼币」这一行的按钮已经是「领取奖励」，点一次。不要再进首页。

### 每一行只允许这三种结局

先看按钮上的字，再动手。

- 按钮是「领取奖励」：点一次。看到「领取成功」或该行按钮消失/变灰，这一条结束。不要进入活动页。
- 按钮是「去完成」：按下面该条的做法做完，然后一路返回，直到重新看到「任务奖励」列表。返回后这一行如果变成「领取奖励」，再点一次。
- 当前屏幕没有这一行：只在任务列表内部向上滑一屏。最多滑 4 屏。仍没有就记为「未找到」，做下一条。不要滑进商品瀑布流。滑出去了就滑回来。

同一条连续两次没有回到任务列表，就跳过这一条，不要换一种点法继续试。

### 迷路时怎么回来

只按返回键，直到屏幕上重新出现「任务奖励」列表。禁止用「重新打开闲鱼」来找回列表。重新打开会掉进淘宝。

如果按了两次返回仍不是任务列表，而且当前也不在闲鱼：再按返回离开外部应用。仍然回不到列表时，只允许重新打开闲鱼一次，然后从头做「右上角领图标 → 关弹窗 → 任务奖励」。这一次之后如果还不在列表上，就结束任务并报告卡在哪一页。不要在淘宝、支付宝、美团里继续找任务。

### 广告和弹窗

- 只点关闭、跳过、关闭广告、残忍离开。
- 不要点查看详情、下载、打开、继续玩、去赚、立即购买。
- 出现「请选择地址」、付款、发布页、草稿箱时，立刻返回，并把当前这条记为跳过。

### 结束
